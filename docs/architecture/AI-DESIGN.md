# AI design and authority

A checkpointed LangGraph investigator uses bounded evidence tools and public corrective feedback. Independent SQL verification and a real dbt workflow check restricted patches across five fixtures and four output relations. PostgreSQL coordinates separate workers and optional graph checkpoints; workspace files still require shared same-node storage.

The private investigator uses the official async Anthropic SDK with bounded typed tool requests, context/token/round limits and explicit live selection. The guided public app uses the deterministic fixed SQL investigator and the independent regression verifier.

Public evidence, schema/query tools and cited findings are distinct from evaluator-owned regression snapshots and source-reference computations. Exported workers receive an explicit runtime; evaluator/application paths are not added to their imports.

Provider transport tests and the fixed diagnostic cases exercise the engineering behavior. [Agent implementation](AGENT-ORCHESTRATION.md).
