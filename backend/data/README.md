# Versioned data

- `benchmark/manifest.json`: frozen 38-case corpus with case hashes and calibration and evaluation splits.
- `benchmark/safety-manifest.json`: frozen eight-case suite for repair, no-change, missing-authority, and hostile-text cases.
- `development/`: revenue contract and current SQL for the development incidents.
- `pricing/`: model pricing profile used by the spend ledger.

All records are original synthetic data. [Data model](../../docs/architecture/OVERVIEW.md#data-and-fixtures) · [Evaluation](../../docs/evaluation/README.md).
